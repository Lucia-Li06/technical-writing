### 关于本项目

本项目提供医疗设备智能化管理服务，可用于大型医院，快速实现医疗设备设备接入，部署、集成、运维和管理。

在本项目中，工程师需要搭建EdgeX Foundry服务器与蓝牙定位系统的架构并进行配置。在配置完成后，可通过UI界面查看医疗设备的位置、电量、运动轨迹等信息。<br>
本项目文档介绍了如何部署EdgeX Foundry软件并进行相关的配置。

### 读者对象

本项目文档主要适用于IoT架构的安装部署和开发人员。您需要具备以下经验和技能：<br>
- 对IoT架构和EdgeX Foundry有基本的了解。<br>
- 熟悉Linux和Docker容器的操作。<br>
- 熟悉网络基础知识。<br>
