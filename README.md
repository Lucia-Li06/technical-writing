### 关于本项目

在IoT项目中，工程师需要搭建EdgeX Foundry服务器与IoT设备网关的架构并进行配置。在配置完成后，可通过调用API或MQTT接口控制IoT设备。<br>
本项目文档介绍了如何部署EdgeX Foundry软件并进行相关的配置，并提供了IoT设备API和MQTT接口的调用方法。

### 读者对象

本项目文档主要适用于IoT架构的安装部署和开发人员。您需要具备以下经验和技能：<br>
- 对IoT架构和EdgeX Foundry有基本的了解。<br>
- 熟悉Linux和Docker容器的操作。<br>
- 熟悉网络基础知识。<br>
