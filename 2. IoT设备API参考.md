## 2. 查询EdgeX Foundry服务器信息
### 2.1 查询主机信息
**URI**

```html
GET /api/v2/device/name/metrics/hostInfo
```

**请求**<br>
样例：

```html
GET http://{EdgeX Foundry IP地址}:59882/api/v2/device/name/metrics/hostInfo
```

**响应**<br>
响应参数：
| 名称  | 参数类型 | 说明                                                                         |
| ----- | -------- | ------ |
| hostname | String   | 主机名称 |
| uptime | Int | 自启动后经历的时间（秒） |
| bootTime | Int | 启动时间（秒） |
| os | String | 操作系统 |
| platform | String | 平台名称 |
| platformFamily | String | 平台系列 | 
| platformVersion | String | 平台版本 | 
| kernelVersion | String | 内核版本 |
| kernelArch | String | 内核架构 |  

其他参数请参考[7.1 响应公共参数](#71-响应公共参数)。<br>

样例：
```html
{
    "apiVersion": "v2",
    "statusCode": 200,
    "event": {
        "apiVersion": "v2",
        "id": "67ed280f-dec5-4107-94d0-b9ad7e60628b",
        "deviceName": "metrics",
        "profileName": "METRIC",
        "sourceName": "hostInfo",
        "origin": 1635473444318662031,
        "readings": [
            {
                "id": "8b2683ab-eede-46b6-93ea-2b455541a1c6",
                "origin": 1635473444318660487,
                "deviceName": "metrics",
                "resourceName": "hostInfo",
                "profileName": "METRIC",
                "valueType": "String",
                "value": "{\"hostname\":\"device-metric\",\"uptime\":522776,\"bootTime\":1634950669,\"os\":\"linux\",\"platform\":\"alpine\",\"platformFamily\":\"alpine\",\"platformVersion\":\"3.12.7\",\"kernelVersion\":\"5.11.0-38-generic\",\"kernelArch\":\"x86_64\"}"
            }
        ]
    }
}

```

返回码：<br>
接口正常的返回码为2xx，例如200或者204。<br>
返回码含义以及更多返回码，请参考[7.2 返回码](#72-返回码)。

## 7. 附录
### 7.1 响应公共参数
下表列出了接口响应中readings字段下的公共参数：
| 名称 | 参数类型 | 说明 |
| --- | --- | --- |
| origin | Int	| 请求编号 |
| deviceName | String | 设备名称|
| resourceName	| String | 操作命令| 
| profileName	| 	String	| 设备配置文件名称|
| valueType	| String | value字段的类型| 

### 7.2 返回码
**正常时的返回码**
| 返回码 | 说明 |
| --- | --- |
| 200	| 请求成功。|
| 204	| 请求成功，但无返回信息。|

**异常时的返回码**
| 返回码 | 说明 |
|--- | --- |
| 404	| 无法找到所请求的对象。| 
| 500	| 请求未完成，服务器异常。| 
| 503	| 请求失败，服务不可用。|
