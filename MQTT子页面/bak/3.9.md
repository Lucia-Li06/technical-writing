### 3.9 设置空调风速主题
**主题说明**
此主题用来设置EdgeX Foundry中注册的空调设备的风速。

**发送主题**

```html
request_topic/command_put
```

**响应主题**

```html
response_topic/command_put
```
**命令格式**：WindSpeedSet_{空调的控制寄存器地址}
关于如何获取空调的控制寄存器地址，请参考“附录”。

**主题信息**

```html
{
    "requestUUid":"ce123409-42f1-5ce5-12e0-334dfh5a1b1d",
    "methodUrl":"http://edgex-core-command:48082/api/v1/device/3605fe85-cbdc-4e87-8db9-2befe6a9c380/command/b8a5887a-816a-4635-8af2-dbe740dfde97",
    "methodParam":{
    "WindSpeedSet_4132":"2"
}
}
```
空调的风速
1：高速
2：中速
4：低速


**接口响应**

响应参数：
|     响应字段       |     字段类型    |     字段描述                  |     说明                                                                                                                 |
|--------------------|-----------------|-------------------------------|--------------------------------------------------------------------------------------------------------------------------|
|     requestUUid    |     String      |     返回请求的唯一标识        |     用来标记每一次的请求                                                                                                 |
|     edgexCode      |     String      |     EdgexFoundry的响应码      |     此响应码是用来反映EdgexFoundry在处理请求时是否成功。     若成功则返回“200”；     若失败则返回相对应的错误码。        |
|     edgexMsg       |     String      |     EdgexFoundry的响应信息    |     此响应信息是对应于响应码的描述。     若成功则返回“Edgex端处理请求成功!     ”；     若失败则返回相对应的错误描述。    |
|     edgexbody      |     String      |     EdgexFoundry的响应体      |     用来返回EdgexFoundry处理请求后需要返回的数据。在此接口中返回的是设备命令PUT请求的响应数据，一般为空字符串。          |

响应示例：

```html
{
    "requestUUid": "ce123409-42f1-5ce5-12e0-334dfh5a1b1d",
    "edgexCode": "200",
    "edgexMsg": "Edgex端处理请求成功!",
    "edgexbody": ""
}
```
