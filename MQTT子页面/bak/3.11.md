### 3.11 获取空调故障状态主题
**主题说明**
此主题用来获取EdgeX Foundry中注册的空调设备的故障状态。

**发送主题**

request_topic/command_get

**命令格式**：ErrorGet_{空调的状态寄存器地址}
关于如何获取空调的状态寄存器地址，请参考“附录”。

**响应主题**

response_topic/command_get

**主题信息**

```html
{
    "requestUUid":"ce123411-42f1-5ce5-12e0-334dfh5a1b1d",
    "methodUrl":"http://edgex-core-command:48082/api/v1/device/3605fe85-cbdc-4e87-8db9-2befe6a9c380/command/8106398a-f648-4348-9102-c208969e8257",
    "methodParam":null
}
```

**接口响应**
响应参数：
|     响应字段        |     字段类型    |     字段描述                  |     说明                                                                                                                 |
|---------------------|-----------------|-------------------------------|--------------------------------------------------------------------------------------------------------------------------|
|     requestUUid     |     String      |     返回请求的唯一标识        |     用来标记每一次的请求                                                                                                 |
|     edgexCode       |     String      |     EdgexFoundry的响应码      |     此响应码是用来反映EdgexFoundry在处理请求时是否成功。     若成功则返回“200”；     若失败则返回相对应的错误码。        |
|     edgexMsg        |     String      |     EdgexFoundry的响应信息    |     此响应信息是对应于响应码的描述。     若成功则返回“Edgex端处理请求成功!     ”；     若失败则返回相对应的错误描述。    |
|     edgexbody       |     String      |     EdgexFoundry的响应体      |     用来返回EdgexFoundry处理请求后需要返回的数据。在此接口中返回的是设备命令请求的响应数据。                             |
|     device          |     String      |     设备对应的网关名称        |     edgexbody中的数据结构。                                                                                              |
|     origin          |     long        |     时间戳                    |     edgexbody中的数据结构，标识唯一性。                                                                                  |
|     readings        |     Json数组    |     设备命令对应的数据参数    |     edgexbody中的数据结构。                                                                                              |
|     origin          |     long        |     时间戳                    |     readings中的数据结构，标识唯一性。                                                                                   |
|     device          |     String      |     设备对应的网关名称        |     readings中的数据结构。                                                                                               |
|     name            |     String      |     设备命令名称              |     readings中的数据结构。                                                                                               |
|     value           |     String      |     设备命令返回值            |     readings中的数据结构。     空调的状态码     0：无故障。     其他值：设备故障，请联系中弘的技术支持。                 |
|     valueType       |     String      |     设备命令返回值类型        |     readings中的数据结构。                                                                                               |
|     EncodedEvent    |     null        |     未知                      |     edgexbody中的数据结构，未使用。                                                                                      |
