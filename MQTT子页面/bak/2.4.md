### 2.4 设备控制消息主题

**主题说明**
该主题用来控制EdgexFoundry中注册的音乐安卓设备对应的设备。

**订阅主题**

```html
request_topic/command_put
```

**响应主题**

```html
response_topic/command_put
```

**主题信息**

```html
{
	"methodUrl":"http://edgex-core-command:48082/api/v1/device/73e5aa47-9cdb-44fe-844c-3faf8598309e/command/f2929af5-12dd-497a-a66d-759157ab559b",

	"device_control":"{\"mac\":\"38CA73126BCB\",\"switch\":0,\"backlight\":100,\"volume\":100,\"rotation\":0}"
}
```
设备开关switch:1 开，0 关

设备音量volume:范围 0-100

设备音量volume:范围 0-100

设备屏幕方向rotation:0,90,180,270


**接口响应**
响应参数：
|     响应字段       |     字段类型    |     字段描述                  |     说明                                                                                                                 |
|--------------------|-----------------|-------------------------------|--------------------------------------------------------------------------------------------------------------------------|
|     requestUUid    |     String      |     返回请求的唯一标识        |     用来标记每一次的请求                                                                                                 |
|     edgexCode      |     String      |     EdgexFoundry的响应码      |     此响应码是用来反映EdgexFoundry在处理请求时是否成功。     若成功则返回“200”；     若失败则返回相对应的错误码。        |
|     edgexMsg       |     String      |     EdgexFoundry的响应信息    |     此响应信息是对应于响应码的描述。     若成功则返回“Edgex端处理请求成功!     ”；     若失败则返回相对应的错误描述。    |
|     edgexbody      |     String      |     EdgexFoundry的响应体      |     用来返回EdgexFoundry处理请求后需要返回的数据。在此接口中返回的是设备命令PUT请求的响应数据，一般为空字符串。          |


响应示例：

```html
{
    "requestUUid": "71bba1v9-320a-4c14-113b-ab421cv15gd0",
    "edgexCode": "200",
    "edgexMsg": "Edgex端处理请求成功!",
    "edgexbody": ""
}
```
