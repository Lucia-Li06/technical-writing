### 2.6 音乐控制消息主题

**主题说明：**
此主题用来控制EdgexFoundry中注册的音乐安卓设备对应的音乐。

**订阅主题**

```html
request_topic/command_put
```

**响应主题**

```html
response_topic/command_put
```

**主题信息**

```html
{
    "requestUUid":"64ab903d-dc12-5803-70dc-d7210daf102b",
    "methodUrl":"http://edgex-core-command:48082/api/v1/device/73e5aa47-9cdb-44fe-844c-3faf8598309e/command/1f7a319a-d734-4966-a3d3-529472572e3d",
    "methodParam":{
     "music_control":"{\"mac\":\"38CA73126BCB\",\"action\":\"pause\",\"audio_id\":0}"
    }
}
```

音乐控制命令action：
play：播放
pre：上一首
next：下一首
pause：暂停
prelist：上一个歌单
nextlist：下一个歌单
jump：切换
音乐文件ID audio_id：jump时输入音乐文件ID，其它情况置0.

**接口响应**
响应参数：

|     响应字段       |     字段类型    |     字段描述                  |     说明                                                                                                                 |
|--------------------|-----------------|-------------------------------|--------------------------------------------------------------------------------------------------------------------------|
|     requestUUid    |     String      |     返回请求的唯一标识        |     用来标记每一次的请求                                                                                                 |
|     edgexCode      |     String      |     EdgexFoundry的响应码      |     此响应码是用来反映EdgexFoundry在处理请求时是否成功。     若成功则返回“200”；     若失败则返回相对应的错误码。        |
|     edgexMsg       |     String      |     EdgexFoundry的响应信息    |     此响应信息是对应于响应码的描述。     若成功则返回“Edgex端处理请求成功!     ”；     若失败则返回相对应的错误描述。    |
|     edgexbody      |     String      |     EdgexFoundry的响应体      |     用来返回EdgexFoundry处理请求后需要返回的数据。在此接口中返回的是设备命令PUT请求的响应数据，一般为空字符串。          |

响应示例：

```html
{
    "requestUUid": "64ab903d-dc12-5803-70dc-d7210daf102b",
    "edgexCode": "200",
    "edgexMsg": "Edgex端处理请求成功!",
    "edgexbody": ""
}
```
